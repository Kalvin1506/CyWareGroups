# CyWareGroups landing page

A responsive, deployment-ready multi-page website for a cybersecurity consultancy offering red team, blue team, cloud/application security, and advisory services.

Pages include Home, Services, About, Contact, Privacy, and a custom 404 response. The enquiry form prepares a structured email to `hello@cywaregroups.com` using the visitor's email application, so it works without a third-party form service.

## Preview locally

Serve the repository root with any static server, then open `/dist/`.

Confirm that `hello@cywaregroups.com` is monitored before public launch. For server-side form submission, connect the form to a trusted CRM or form endpoint.
